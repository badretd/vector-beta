# Vector 0.1.0

The first packaged desktop release of Vector: a local voice companion that
listens through your microphone, transcribes speech locally with Whisper,
streams replies from Ollama, and reacts with a tiny animated pixel face.

## Downloads

| Platform | File |
| --- | --- |
| Windows 10/11 (x64) | `Vector-0.1.0-windows-x64-Setup.exe` |
| macOS 11+ (Apple Silicon) | `Vector-0.1.0-macos-arm64.dmg` |
| macOS 11+ (Intel) | `Vector-0.1.0-macos-x86_64.dmg` |
| Linux (x86_64) | `Vector-0.1.0-linux-x86_64.AppImage` |
| Linux (x86_64) | `Vector-0.1.0-linux-x86_64.tar.gz` |

`SHA256SUMS.txt` contains checksums for every asset.

## Before you start

- Install **Ollama** and pull a model: `ollama pull qwen2.5:3b`.
- Install Chrome, Chromium, Brave, or Edge for the app window.
- The first launch downloads the ~466 MB Whisper speech model.

## Changes

- Windows installer, macOS DMGs, and Linux AppImage/tarball.
- Per-user data storage, so installed builds work from read-only locations.
- Cross-platform browser detection for app-window mode.
- New `--self-test` and `--version` commands.
- Tag-driven release pipeline with tests, build smoke tests, and checksums.

See [`CHANGELOG.md`](https://github.com/badretd/vector-beta/blob/main/CHANGELOG.md)
for the full list.

## Notes

- Windows and macOS builds are signed only when the release signing secrets are
  configured.
- Vector never speaks aloud; there is no text-to-speech.
- Audio and text stay on your machine.
